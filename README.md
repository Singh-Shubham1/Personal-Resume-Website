# 🌐 Personal Resume Website

A modern, responsive Personal Portfolio Website built using **HTML, CSS, and JavaScript**. This project showcases my skills, projects, and contact information in a professional and user-friendly interface.

## 📌 Features

- 🏠 Home Section
- 👤 About Me
- 💻 Skills Section
- 📂 Projects Showcase
- 📞 Contact Form
- 📄 Resume Download Button
- 🌙 Dark/Light Mode Toggle
- ⌨️ Typing Animation
- ⬆️ Scroll to Top Button
- 📱 Fully Responsive Design
- 🔗 Social Media Links (LinkedIn, GitHub, Instagram)
- 🎨 Modern UI with Hover Effects & Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
- Google Fonts

## 📂 Project Structure

```
Portfolio-Website/
│── index.html
│── style.css
│── script.js
│── profile.jpg
│── resume.pdf
│── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it using Live Server in Visual Studio Code.
